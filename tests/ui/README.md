## 复现

在隔离测试机安装或复用 Playwright，放置本仓库的 `assets/` 与 `tests/ui/`，指定可用 Chromium。不要在生产目录运行。

```sh
export NODE_PATH=/path/to/node_modules
export CHROME_BIN=/path/to/chromium
export UI_OUTPUT=/path/to/results
node tests/ui/console.cjs
# UI_BINARY 必须指向本分支最新构建；测试自行创建 / 清理独立目录与回环监听实例。
UI_BINARY=/path/to/apwatch python3 tests/ui/live.py
```

`fixture.cjs` 仅含合成数据，`console.cjs` 拦截全部网络；`live.py` 管理真实临时服务的生命周期，`live.cjs` 只允许请求该临时服务地址。
